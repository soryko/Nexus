# Nexus saved-revision inspector (workspace build)

The host contract for the client is `ctx.remote.nexusInspector.open(agentId, seq)`. The host's dependencies are `@deepseek-ai/dsh-typert-protocol` and `@deepseek-ai/dsh-tool-executor-native`; the loader must resolve versions matching its DSH runtime. The response may also carry `originSeq` for returning to the originating turn. Receipt identity does not attest physical database generation; do not enable this on a rebound store without independently verifying its binding.

The sequence points to a committed capture-success notice in that session. Never accept a memory ID, revision ID or database path from the browser. The host resolves IDs from the receipt and performs one guarded historical `get`. A successful result contains `status: 'ok'`, `memoryId`, `savedRevisionId`, `currentRevisionId`, `content`, `turn`, and `seq`. Other outcomes must not expose a body. The UI says **Saved memory**, not **Filed**, since these receipts do not prove space placement.

Live read-only Client inspection verified `conversation.chat.turnTail` as an additive, session-scoped list. It receives `{ turn, seq, openFile }`, `sessionId`, projection hooks and `useSessionAccess`; `seq` here is the **closing sequence**, not the receipt sequence. Register a fresh id beside the shipped Mnemon and deliverables cues. The strict Zod wire contract is in `descriptor.js` and is inlined into `client.js` by `build-client.mjs`.

The session-only wire projection `nexusInspectorReceipts` has shape `{ turns: { [originTurn]: [{ seq }] } }`. Each `seq` is a committed `agent/inbox/spliced` capture-success receipt, not a turn boundary. A cue reads only this metadata on mount. On explicit open, send that seq and the slot's session ID; never send memory or revision IDs. The projection matches `dsh-memory:` plus SHA256 of `<sessionId>:<originSeq>` against eligible root-session origins rather than the notice's retry turn. It keeps the last 256 unmatched origins and up to 8 receipts per turn for the newest 32 represented turns. Missing or evicted matches produce no cue. Open separately checks the stored `source_uri` against the same session and origin.

## Verification (from repository root)

- `node --test integrations/dsh-inspector/tests/host.test.mjs integrations/dsh-inspector/projection.test.js`: receipt admission, projection bounds and original-turn mapping, access, error and cancellation cases.
- `.venv/bin/python -m pytest -q tests/tools/test_dsh_saved_revision.py`: a synthetic DSH session drives the real host adapter against a real disposable Nexus MCP store. It checks exact historical text, current-revision identity and unchanged durable counters.
- `DSH_CHECKOUT=/absolute/path/to/deepseek-harness node integrations/dsh-inspector/tests/client-browser.mjs`: isolated Chrome mounts the actual client factory with fixture DSH props/RPC, clicks a cue, checks literal saved text, and returns keyboard focus to the turn.

The cue now opens the native session **right-side inspector** rather than expanding inline. It is not the full Atlas library. An [installed side-panel GUI-to-store test](../../docs/measurements/dsh-inspector-side-panel-installed.json) passed with a synthetic receipt in a disposable profile: no read on mount, exactly one pinned `get` on click, exact historical text, and focus returned to the originating cue. Reproduce with `DSH_CHECKOUT=/absolute/path/to/deepseek-harness .venv/bin/python integrations/dsh-inspector/tests/run-installed.py`. Do not install into a live profile during development.
