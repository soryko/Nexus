# Nexus memory provider (A12 candidate)

This is a Memory Spaces **child module**, not a top-level Cordis bundle or a UI. Declare `use: dsh-mnemon-provider-nexus` under a Memory Spaces Source's `providers`. No active profile installation or registry publication is part of verification. The Source owns display; the descriptor supplies its title, summary and glyph.

Child config is trusted deployment input. `bindings` maps an opaque connection name to `{executable, args, journalDir?, atlasOrigin?}`. Supply an absolute installed `nexus-memory-bridge` executable and `['--catalog', absoluteCatalog, '--grant-file', absolutePrivateTicket]`. The ticket is the existing launcher's private grant-id file; protocol requests cannot change it. Select only an owner-approved alias using the Source's `binding` connection field. Do not reuse a binding for a different grant. `atlasOrigin` may identify an already-running loopback scoped Atlas viewer for the same space. Links identify a revision without containing credentials; the viewer requires its own session and current mount. Absent a viewer, no link is invented.

Declarative mounts are read-only, even with `audience: isolated-writer` or `single-project`. A host using the programmatic `forAuditedHost` export may enable writes only after verifying its complete active Source and receiving-project configuration and pinning that exposure until disposal. A child configuration or body cannot supply that attestation. Require a dedicated private `journalDir` for each writer binding; do not share it across processes, Sources or grants. It stores pending content, not just hashes. Provision a read-only grant for mixed profiles as defense in depth. The backend fence still checks every grant.

Each new remember invocation gets a fresh operation key; internal contention retry keeps it. A transport failure after sending is not proof of failure to commit. Reconciliation only reads; `absent_at_snapshot` and unavailable results leave the private entry for later inspection. Never resubmit an ambiguous invocation under a new key. The SDK has no stable cross-invocation retry identity. Search uses provider-native lexical scores; get returns the current visible head. Browse, graph, entities, related, link and forget are not implemented. Source/category/entities/importance are unverified compatibility metadata, not verified authorship or graph evidence.

## Reproduce

Use a disposable worktree and `uv sync --frozen` at its root. Put fixture Node 22.19.0 and pnpm 10.13.1 first on PATH (no global replacement). From this directory run `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm build`, `pnpm test`, `pnpm test:packed`, and `pnpm test:loader`. From the root run `uv run pytest -q tests/transport/test_dsh_bridge.py`. The external fixtures use temporary package directories, an allowlisted environment without NODE_PATH, and fresh profile/data roots. Set `NEXUS_FIXTURE_STORE` to reuse a disposable pnpm store.
