# Nexus Memory v0.1.0a3 — experimental developer prerelease

**Experimental.** It stores your bytes and gives them back after a restart, and that part is
tested. **No benefit to a coding agent has been shown**, and nothing in this release changes
that. The one held-out comparison that has run found none.

This release adds ways to *look at* and *connect to* a store. It does not change what is
stored: **the database schema is unchanged since v0.1.0a2** (no migration files differ), so a
v0.1.0a2 and a v0.1.0a3 client can share one database.

## What changed

**Memory Atlas, a read-only viewer.** `launcher.py atlas <checkout>` (from the project-scope
integration) opens a loopback-only browser page for one enrolled project: counts by kind,
search with kind/tag/repository/path filters, a memory's text and revision history, its
related memories, and a bounded graph of the files it cites and the memories that cite them
(at most 100 nodes and 150 edges). It opens the store read-only, never enrolls or migrates,
shows **no agent activity**, works by keyboard and at 360 px, and listens only on `127.0.0.1`
behind a one-time launch secret. Measured on one MacBook Pro with 10,000 memories: cold
launch to counted overview p95 116 ms, warm selection p95 33 ms (targets 2000 and 300);
definitions and raw samples are in `docs/measurements/2026-11-06-atlas-benchmark.json`. Known
limits are listed in the README, among them: a memory's own relations are not pageable past
100, and on Linux a checkout whose `.git` is deleted and recreated can reuse its inode
undetected. Viewing needs this release's package: an older installed runtime prints
"does not include Atlas".

**Project-scoped stores.** The project-scope launcher binds a Git checkout to its own private
database through an owner-only enrollment, for Codex, Claude and Antigravity, plus
`tools/retire_legacy_store.py` to retire a shared store safely.

**Server instructions, richer `status`, and an opt-in usage log.** `--capture-policy
explicit|autonomous`, `--no-instructions`, `--usage-log`, new `status` fields (namespace,
actor, version, instructions digest, database location fingerprint) and an offline usage
reporter. See the README section "What the server tells the model, and what it records".

**Host hooks.** `--hook-project-root` (alias `--codex-project-root`), `--hook-unenrolled`,
host-neutral hook tools, an opt-in Codex Desktop adapter, and a Claude Code plugin skeleton
(`integrations/claude-plugin`). The Claude plugin's interactive checks have not been run by
a person; treat it as unverified.

**Search and storage.** Bounded search excerpts, literal-lookup and migrated browse-order
repairs, and private SQLite backups that publish only completed copies.

**License.** The project is now licensed under PolyForm Noncommercial 1.0.0 with commercial
permission guidance (`LICENSE`, `NOTICE`, `LICENSING.md`). Read it before using the project.

## What this release still does not claim

No benefit to a coding agent has been shown. The environment is not relocatable; the Python
runtime it was built from must stay put. Still local, single-user and trusted: no remote
authentication, no encryption at rest, no multi-tenancy. Linux and macOS; Windows remains
unverified. No PyPI package and no standalone binary.

## Install

```bash
git clone https://github.com/soryko/Nexus.git
cd Nexus
git checkout v0.1.0a3
nexus_runtime="$HOME/.local/share/nexus-memory/venvs/0.1.0a3"
python3 tools/install.py --venv "$nexus_runtime"
"$nexus_runtime/bin/nexus-memory-check"
```

Expect `PASS: 9/9 checks`. Full instructions and the update procedure:
[`docs/experimental-release.md`](https://github.com/soryko/Nexus/blob/v0.1.0a3/docs/experimental-release.md).

## Upgrading from v0.1.0a2

Build a new environment beside the old one and change the client's `command` path; rollback
is a path change. The database needs no migration. Installing this release does not by
itself change any client configuration or the installed project-scope launcher: copy
`integrations/project_scope/launcher.py` over the installed one yourself, after backing it up.
